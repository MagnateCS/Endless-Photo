# Project conventions

## Typography

Follow [TYPOGRAPHY.md](TYPOGRAPHY.md) for all website typography. The approved scale lives in `assets/css/typography.css`. Use semantic `type-*` classes and keep sizes, font families, weights, line heights, and letter spacing consistent everywhere. Do not introduce per-page or responsive typography utility overrides. Change the shared scale only when the user requests it, and update the reference table with any approved changes.
